# Как применить каркас и запустить Claude Code

## 1. Подготовка проекта

1. В Android Studio: **New Project → Empty Activity (Compose)**
   - Name: `Cardamom`
   - Package: `io.github.wizard302.cardamom`
   - Minimum SDK: 26
2. Убедись, что проект собирается «из коробки» (Build → Make Project).
3. **Удали** сгенерированные шаблоном файлы:
   - `app/src/main/java/io/github/wizard302/cardamom/MainActivity.kt`
   - `app/src/main/java/io/github/wizard302/cardamom/ui/theme/` (всю папку)
4. Скопируй содержимое этого архива **поверх корня проекта**, соглашаясь на замену
   (`build.gradle.kts`, `app/build.gradle.kts`, `gradle/libs.versions.toml`,
   `AndroidManifest.xml`, `strings.xml`, `themes.xml`, весь `java/io/github/wizard302/cardamom/`).
   `CLAUDE.md` и `PLAN.md` должны лежать в корне проекта.
   Gradle wrapper и `local.properties` из шаблона НЕ трогай.

## 2. Запуск Claude Code

В терминале, в корне проекта:

```
claude
```

Первый промпт (скопируй целиком):

```
Прочитай CLAUDE.md и PLAN.md. В проект уже добавлен стартовый каркас Фазы 1
(написан без возможности компиляции — в нём могут быть ошибки версий и API).

Шаг 1. Сверь gradle/libs.versions.toml с версиями из шаблона Android Studio
(AGP, Kotlin, KSP должны быть согласованы) и собери проект:
./gradlew assembleDebug. Чини ошибки, пока сборка не пройдёт. Логику и
архитектуру каркаса сохраняй — исправляй только реальные ошибки.

Шаг 2. Установи APK на подключённое устройство (adb install) и скажи мне
проверить: список дорожек, воспроизведение по тапу, мини-плеер, экран
«Сейчас играет», уведомление.

Шаг 3. После моего подтверждения продолжай по чек-листу Фазы 1 в PLAN.md
(отмечай выполненные пункты). Осталось: вкладка Folders, drill-down
экраны исполнителей и альбомов, контекстные меню (Play next / Add to
queue / Details), панель очереди с перетаскиванием, быстрая прокрутка,
сохранение очереди и позиции между запусками, ручной переключатель темы.
Коммить после каждого работающего инкремента.
```

## 3. Что уже сделано в каркасе (пункты чек-листа Фазы 1)

- Каркас проекта: Compose, Material 3, Hilt, тема с Material You и тёмным фолбэком
- Разрешения (READ_MEDIA_AUDIO / READ_EXTERNAL_STORAGE + POST_NOTIFICATIONS) с экраном-заглушкой
- Сканер MediaStore → репозиторий с Flow дорожек/альбомов/исполнителей, авто-обновление через ContentObserver
- Вкладки Artists / Albums / Tracks (+ заглушки Playlists / Folders), обложки через Coil
- Media3 MediaSessionService: аудиофокус, пауза при отключении наушников, уведомление
- Тап по дорожке = воспроизведение всей вкладки с этой позиции
- Мини-плеер с прогрессом; экран «Сейчас играет»: обложка, слайдер перемотки, shuffle/repeat, позиция в очереди (x/y)

## 4. Известные упрощения (Claude Code доделает)

- Drill-down по исполнителю/альбому — TODO-заглушки в CardamomApp.kt
- Вкладка Folders — заглушка
- Очередь не сохраняется между перезапусками (пункт чек-листа)
- Переключение темы вручную (DataStore) не подключено — только системная
- Строки пока только на английском (русский — Фаза 6 по плану)
